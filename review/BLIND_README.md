# Stage 1 — blind visual packet

This packet contains current-source presentation images and no mechanical or
source explanation. That omission is deliberate.

1. Review every file in `images/`.
2. Paste `01_PROMPT.md` into a fresh reviewer conversation.
3. Ask the reviewer to fill out `03_RESPONSE_TEMPLATE.md`.
4. Save the completed response before sharing any second-stage context.

Do not use visual overlap alone as proof of a physical collision. The purpose
of this stage is to capture how the product reads before technical facts anchor
the reviewer.

Save the response as `GROK_01_BLIND_VISUAL_AUDIT.md` or
`CLAUDE_01_BLIND_VISUAL_AUDIT.md` before opening the context packet.
