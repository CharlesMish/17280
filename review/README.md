# Historical review material

This directory preserves review inputs and intermediate technical-truth snapshots from the development of **17280**.

These files are intentionally kept as historical records. They may describe open findings, review-candidate status, camera problems, or mechanical issues that were repaired later in the project. Do not treat an older review document as the current release state simply because it remains in the repository.

For the current public framing, start with the repository [README](../README.md), [RC1 release notes](../RELEASE_NOTES_RC1.md), and [known limitations](../KNOWN_LIMITATIONS.md).

The point of keeping this material is provenance: it shows what reviewers saw, what they got wrong or right, and what changed afterward.
